# Public Sources only: no Firm documents are uploaded or stored

The Corpus holds only published regulatory texts. Compliance Officers cannot upload internal policies, contracts or other Firm documents, so gap analysis against a Firm's own documents is not offered, although it would be valuable. Confidential documents would otherwise reach an external model provider, and a bank's or insurer's first question about any such tool is where its data goes. Questions themselves still go to the Answer Model, so a pre-check removes obvious personal data and the interface tells them not to enter confidential details; an EU-hosted model can be chosen. Revisiting this needs a hosting and data-protection concept first. Decided in the feature session of 2026-10-22.
