# Optional accounts; answers are private to their account

Accounts were added on 2026-10-23 so a Compliance Officer can keep a Firm Profile, a dashboard and a searchable archive of their own questions. Accounts are optional: without one the app works as before, and guest answers stay in a shared guest history. An account's answers are visible only to that account; asking for another account's answer returns "not found" rather than "forbidden", so ids reveal nothing. Accounts hold an email address, a name, the Firm Profile and the answers, which is personal data: passwords are stored only as salted scrypt hashes, sessions only as SHA-256 hashes of random tokens in an httpOnly cookie, and deleting an account deletes its answers too. There is no email verification and no password reset, because both need a mail service; that is the first thing to add before real users. Rejected for now: logins through an identity provider (Microsoft Entra ID, as large banks and insurers use), which is the likely target for a real deployment but needs a tenant to test against.
